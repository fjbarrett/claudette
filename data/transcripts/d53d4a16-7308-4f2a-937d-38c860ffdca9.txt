Hypothetical coding task: write a JavaScript function that debounces a callback and explain the edge cases in two sentences.

[ASSISTANT]
Here is an example of a JavaScript debounce function:
```javascript
function debounce(callback, delay) {
  let timeoutId = null;
  return function() {
    clearTimeout(timeoutId);
    timeoutId = setTimeout(callback, delay);
  };
}
```
Edge cases to consider: If the `delay` parameter is set to a value less than or equal to zero, the debouncing behavior will be invalid, as it will not provide any delay between function calls. Additionally, if the callback function passed to `debounce` throws an error and the timeout is cleared, the error will not be caught by the wrapper function, potentially causing issues in the application.

Example usage:
```javascript
const debouncedLog = debounce((message) => console.log(message), 500);
debouncedLog('Hello'); // logs "Hello" after a 500ms delay
debouncedLog('World'); // logs "World" after a 500ms delay, even if 'Hello' was called earlier
```
