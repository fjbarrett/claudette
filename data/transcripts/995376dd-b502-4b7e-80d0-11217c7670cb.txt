# Ollama Code Console

Local full-stack coding chat app with a Claude Code-style terminal workflow, backed by Ollama.

## What it includes

- Browser UI with session history, model switching, and streamed responses
- Local CLI with slash commands and streamed chat
- Persistent JSON session storage in `data/sessions`
- `@relative/path` file expansion so prompts can inline workspace files

## Run

```bash
npm start
```

Open `http://127.0.0.1:4321`.

In another terminal:

```bash
npm run cli
```

## Environment

- `PORT`: server port, default `4321`
- `HOST`: bind host, default `127.0.0.1`
- `OLLAMA_BASE_URL`: Ollama API base URL, default `http://127.0.0.1:11434`
- `WORKSPACE_ROOT`: allowed root for `@file` expansion, default repo root

The purpose of this project is to create a **local, full-stack coding chat application** that mimics the workflow of an advanced AI coding assistant (like Claude Code).

It allows users to interact with AI models (specifically backed by Ollama) through two interfaces:
1.  **A Browser UI:** Accessible at `http://127.0.0.1:4321`.
2.  **A Local CLI:** Run via `npm run cli`.

The system is designed to be persistent, storing session history and context in the `data/sessions` directory, and it supports features like `@relative/path` file expansion, allowing prompts to reference files directly within the workspace.
